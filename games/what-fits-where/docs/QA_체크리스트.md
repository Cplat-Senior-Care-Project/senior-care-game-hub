# 오늘의 준비물 QA 체크리스트 v0.4

확인 결과는 `통과 / 부분 통과 / 실패 / 확인 필요 / 미구현` 중 하나로 기록하고, 구체적인 사유는 비고란에 작성한다.

본 문서는 ClickUp `QAT-PRP-001_QA 체크리스트_v0.2`의 기획/개발 체크리스트를 필수 기준으로 포함하고, 첨부 이미지의 `REQ-QA-001~020` 표 구조를 반영해 추가 QA 항목을 `기획 체크리스트`와 `개발 체크리스트` 안에 함께 정리한다.

## 버전 변경 이력

| 버전 | 구분 | 변경 내용 | 기준/비고 |
| --- | --- | --- | --- |
| v0.1 | 최초 작성 | 오늘의 준비물 QA 체크리스트 초안 작성. 기획 화면 흐름, 주요 모드, 문제 화면, 결과 화면 중심의 기본 검수 항목을 구성함 | 초기 QA 초안 |
| v0.2 | ClickUp 기준 반영 | ClickUp `QAT-PRP-001_QA 체크리스트_v0.2`의 기획 체크리스트와 개발 체크리스트를 필수 기준으로 반영함. P계열/D계열 항목과 기존 결과/비고를 유지함 | ClickUp 문서 기준 |
| v0.3 | 요구사항 QA 보강 | 첨부 이미지의 `REQ-QA-001~020` 항목을 반영하고, 실행/UI/모드/문구/오디오/로그/API·DB/산출물 관점의 추가 QA 항목을 보강함 | 이미지 QA 표 기준 |
| v0.4 | 표 구조 정리 | 큰 구분을 `기획 체크리스트`, `개발 체크리스트` 두 개로만 정리함. 중간에 끊기던 표를 각각 하나의 표로 통합하고, 번호를 기획 `P-01~P-95`, 개발 `D-01~D-112`로 연속 정리함. `관련 요구사항` 열을 제거하고, 모든 항목의 `모드 구분`, `검수 방법`, `통과 기준`을 채움 | 현재 문서 |
