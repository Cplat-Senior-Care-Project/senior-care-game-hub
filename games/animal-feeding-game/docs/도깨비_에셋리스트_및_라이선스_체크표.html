1. 에셋 현황 요약

현재 도깨비 게임은 별도 assets/ 폴더 대신 image/, audio/, 루트의 game-thumbnail.png를 실행 에셋으로 사용합니다.

실제 파일 기준 이미지 에셋은 28개, 오디오 에셋은 16개입니다. 폰트 파일은 포함하지 않으며 CSS의 시스템/브라우저 폰트 스택만 사용합니다.

현재 에셋 집계
구분 전체 프로젝트 생성/자체 제작 분류 외부/생성 출처 확인 필요 현재 사용 경로 라이선스 증빙 상태
이미지 28 28 0 image/*.png, game-thumbnail.png 생성/제작 증빙 보관 권장
오디오 16 14 2 audio/bgm/*.mp3, audio/sfx/*.mp3, audio/voice/*.mp3 BGM/SFX 출처 확인 필요
폰트 0개 파일 0 0 CSS 폰트 스택 재배포 폰트 없음
코드 생성 사운드 2종 2 0 js/audio-display.js의 WebAudio 합성음 파일 에셋 아님

주의: 이 문서의 "사용 경로 확인"은 현재 코드와 파일 목록 기준의 기술 점검입니다. 법적 라이선스 확정은 원본 출처, 구매 내역, 생성 서비스 약관, TTS 사용권 증빙까지 보관되어야 완료로 볼 수 있습니다.

변경 반영: 현재 루트의 game-thumbnail.png가 실제 썸네일로 사용됩니다. 이전에 추적되던 image/game-thumbnail.png와 asset-catalog.png는 현재 실행 에셋 목록에서 제외했습니다.

현재 게임 폴더에는 .woff, .woff2, .ttf, .otf 폰트 파일이 없습니다. CSS는 OS 또는 브라우저에 설치된 폰트명을 우선순위로 지정합니다.
