6. 외부/생성 음원 출처

오디오 파일은 게임 UX에서 직접 재생되는 배포 에셋이므로, 이미지보다 우선적으로 출처와 이용 범위를 확정하는 것이 좋습니다.

외부/생성 음원 출처 확인표
대상 파일 현재 사용 확인해야 할 출처 정보 배포 전 판정
BGM audio/bgm/goblin-fate.mp3 공통 배경음 작곡자/생성 서비스, 라이선스명, 구매 또는 생성 증빙, 상업적 앱 배포 가능 여부 확인 전 배포 보류 권장
SFX audio/sfx/button-click.mp3 버튼 클릭 효과음 효과음 제작자/다운로드 URL, 라이선스명, 크레딧 표기 필요 여부 확인 필요
Voice audio/voice/*.mp3 안내 음성 14개 녹음자 또는 TTS 서비스명, 음성 모델 권리, 서비스 약관, 상업적 배포 가능 여부 확인 필요

권장 보관 자료

  • 파일별 원본 출처 URL 또는 제작자명
  • 구매 에셋인 경우 주문 번호, 영수증, 라이선스 전문
  • 무료 에셋인 경우 다운로드 날짜, 라이선스명, 크레딧 표기 조건
  • AI 생성 에셋인 경우 생성 모델, 생성일, 주요 프롬프트, 후가공 내역
  • TTS/음성 생성물인 경우 서비스 약관, 사용 음성 모델, 상업적 이용 가능 여부
