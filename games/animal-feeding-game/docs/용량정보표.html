도깨비야! 무슨 색을 먹니? - 용량정보표

이미지, UI 요소, 배경음, 효과음, 안내 음성 파일의 용량을 정리한 산출물

1. 문서 개요

본 문서는 도깨비 게임에서 사용되는 이미지, UI 요소, 배경음, 효과음, 안내 음성 파일의 용량을 정리한 산출물이다.

게임 실행 시 사용되는 에셋의 전체 규모를 확인하고, 향후 최적화가 필요한 항목을 파악하기 위해 작성되었다.

도깨비 게임은 별도 assets/ 폴더 대신 image/, audio/ 폴더에 배포 에셋이 위치한다. 따라서 본 문서의 에셋 합계는 image/, audio/ 폴더 내 파일을 기준으로 산정했다.

현재 배경음은 audio/bgm/goblin-fate.mp3 1개 파일로 구성되어 있으며, 효과음은 audio/sfx/button-click.mp3 1개 파일, 안내 음성은 audio/voice/ 폴더 내 14개 파일로 구성되어 있다.

3. 주요 확인 내용

전체 에셋은 총 46개이며, 전체 용량은 약 7.32MB이다.

가장 큰 비중을 차지하는 항목은 먹이/선택지 이미지로, 총 14개 파일, 약 2.48MB를 차지한다. 전체 에셋 용량의 약 33.8%에 해당한다.

두 번째로 큰 항목은 도깨비 캐릭터 이미지로, 총 10개 파일, 약 2.33MB를 차지한다. 전체 에셋 용량의 약 31.9%에 해당하며, 이 중 goblin_straw_base.png 1개 파일이 약 1.55MB로 가장 크다.

UI/게임 보조 이미지는 총 4개 파일, 약 1.08MB로 전체의 약 14.7%를 차지한다. 이 항목에서는 feed-basket.png가 약 0.88MB로 가장 큰 비중을 차지한다.

배경음 및 효과음은 총 2개 파일, 약 0.67MB이며, 안내 음성 14개 파일은 약 0.17MB로 상대적으로 용량이 작다. 현재 배경음은 goblin-fate.mp3 1개 파일로 구성되어 전체 에셋 용량의 약 9.1% 수준이다.

5. 정리

현재 도깨비 게임의 실행 에셋 전체 용량은 약 7.32MB이다. 이 중 이미지 에셋은 총 30개 파일, 약 6.48MB로 전체의 약 88.5%를 차지하며, 오디오 에셋은 총 16개 파일, 약 0.84MB로 전체의 약 11.5%를 차지한다.

전체 용량에서 가장 큰 비중은 먹이/선택지 이미지와 도깨비 캐릭터 이미지가 차지한다. 향후 추가 최적화 작업을 진행한다면 goblin_straw_base.png, feed-basket.png, chamoe.png, corn.png, patjuk.png, farm-background.png를 우선적으로 확인하는 것이 효율적이다.

최적화 방향은 다음과 같다.

  • 도깨비 캐릭터 및 배경성 이미지는 실제 표시 크기에 맞춰 해상도를 재검토한다.
  • 먹이/선택지 이미지는 품질을 유지하면서 압축률을 높인다.
  • goblin_straw_base.png와 feed-basket.png는 단일 파일 용량이 크므로 우선 압축 대상으로 확인한다.
  • 배경음은 현재 1개 파일로 구성되어 있으므로, 추가 최적화가 필요할 경우 길이와 음질을 조정한다.
  • 효과음과 안내 음성은 이미 용량이 작아 우선순위가 낮다.
