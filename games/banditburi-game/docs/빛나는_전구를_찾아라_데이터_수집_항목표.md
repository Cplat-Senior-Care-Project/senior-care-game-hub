# 빛나는 전구를 찾아라 데이터 수집 항목표

## 1. 문서 목적

본 문서는 WebView 기반 인지활동 콘텐츠인 `빛나는 전구를 찾아라` 게임에서 수집하는 데이터 항목을 정리하기 위한 문서이다.

데이터 수집 항목표는 게임 실행 중 어떤 데이터가 수집되는지, 언제 수집되는지, 어떤 목적으로 활용되는지를 한눈에 확인하기 위한 개발 산출물이다.

## 2. 수집 범위 및 원칙

| 구분 | 내용 |
|---|---|
| 수집 목적 | 콘텐츠 참여 여부, 위치 기억 수행 흐름, 도움 필요 정도, 중도 종료 여부, 난이도 조정 참고, 보호자/요양원 리포트 활용 |
| 수집 단위 | 게임 1회 실행 세션, 라운드별 결과, 사용자 수행 과정, 게임별 상세값 |
| 결과 반환 방식 | 게임 시작/종료/중도 이탈 시 WebView 게임이 앱에 JSON 메시지 반환 |
| 진단 목적 여부 | 의료적 진단, 인지 저하 판정 목적이 아님 |
| 사용자/보호자 식별값 | `seniorId`, `guardianId`, `assignmentId` 등은 앱/서버가 보유 및 결합 |
| 게임별 확장 데이터 | 공통 필드를 계속 늘리지 않고 `resultDetail` 내부에 저장하는 방식 우선 고려 |
| 케어 모드 수집 방향 | 점수보다 완료 여부, 힌트 사용, 반응 시간, 중도 종료 여부 중심으로 기록 |
| AI 연동 모드 수집 방향 | 게임 자체는 STT/AI 판단을 수행하지 않고, 앱/AI가 전달한 외부 선택값을 입력 결과로 기록 |

## 3. 데이터 구분 요약

| 데이터 구분 | 설명 | 대표 필드 |
|---|---|---|
| 세션 데이터 | 게임 1회 실행 전체에 대한 기본 정보 | `sessionId`, `contentId`, `gameKey`, `mode`, `difficulty`, `startedAt`, `endedAt`, `status` |
| 라운드별 결과 데이터 | 각 라운드에서 사용자가 목표 위치를 찾았는지와 실패 사유 | `resultDetail.rounds`, `roundNo`, `correct`, `failReason`, `durationMs` |
| 과정 데이터 | 실제 수행 흐름과 상호작용 과정 | `correctClickCount`, `wrongClickCount`, `hintCount`, `attemptCount`, `interactionCount`, `totalElapsedMs` |
| 오류 데이터 | 게임 실행 또는 결과 반환 중 발생한 오류 정보 | `errorCode`, `errorMessage`, `status` |
| 게임별 상세값 | 빛나는 전구를 찾아라 게임에서만 의미 있는 특수 데이터 | `resultDetail.theme`, `gridSize`, `targetCountPerRound`, `timeLimitSec`, `targetPolicy` |

## 4. 세션 데이터 수집 항목

세션 데이터는 사용자가 게임을 실행하고 종료하기까지의 전체 참여 흐름을 확인하기 위한 데이터이다.

| 구분 | 수집 항목 | 코드 필드명 | 수집 시점 | 수집 방법/출처 | 수집 목적 | 비고 |
|---|---|---|---|---|---|---|
| 세션 | 스키마 버전 | `schemaVersion` | 메시지 전송 시 | 게임 설정 | 앱/서버 파싱 기준 확인 | 필수 |
| 세션 | 메시지 전송 시각 | `sentAt` | 메시지 전송 시 | 게임 내부 기록 | 앱 수신 시각과 비교 및 디버깅 | 필수 |
| 세션 | 세션 ID | `sessionId` | 게임 실행 시 | 앱 전달 또는 게임 생성 | 실행 세션 매칭 및 중복 저장 방지 | 필수 |
| 세션 | 콘텐츠 ID | `contentId` | 게임 실행 시 | 앱 전달 | 어떤 콘텐츠가 수행되었는지 식별 | 필수 |
| 세션 | 게임 유형 ID | `gameKey` | 게임 실행 시 | 앱 또는 게임 설정 | 위치 기억 게임 통계 분석 | 필수, 기본값 `light_memory` |
| 세션 | 실행 모드 | `mode` | 게임 실행 시 | config 또는 URL 모드 | `standard`, `reminder`, `care`, `ai_assisted` 모드별 결과 해석 | 필수 |
| 세션 | 난이도 | `difficulty` | 게임 시작 시 | 사용자 선택 또는 config | 난이도별 수행 결과 비교 | 필수, `EASY`, `NORMAL`, `HARD` |
| 세션 | 실행 출처 | `playSource` | 게임 실행 시 | 앱 전달 | 수동 실행, 알림, 케어 과제 등 유입 경로 확인 | 권장 |
| 세션 | 시작 시각 | `startedAt` | 게임 시작 시 | 게임 내부 기록 | 실제 플레이 시작 시점 확인 | 필수 |
| 세션 | 종료 시각 | `endedAt` | 게임 종료 시 | 게임 내부 기록 | 실제 플레이 종료 시점 확인 | 필수 |
| 세션 | 수행 시간 | `durationMs` | 게임 종료 시 | 라운드별 수행 시간 합산 | 실제 문제 풀이 시간 분석 | 필수 |
| 세션 | 전체 경과 시간 | `totalElapsedMs` | 게임 종료 시 | `endedAt - startedAt` | 대기/일시정지 포함 이탈 여부 분석 | 권장 |
| 세션 | 실행 상태 | `status` | 게임 종료 시 | 게임 내부 계산 | 완료, 중단, 오류 구분 | 필수 |
| 세션 | 중도 종료 여부 | `abandoned` | 중도 종료 시 | 게임 내부 계산 | 이탈 여부 확인 | 중단 시 필수 |
| 세션 | 중도 종료 사유 | `abandonedReason` | 중도 종료 시 | 게임 내부 상태값 | 홈 이동, WebView 종료 등 원인 확인 | 중단 시 권장 |
| 세션 | 중도 종료 시각 | `abandonedAt` | 중도 종료 시 | 게임 내부 기록 | 이탈 시점 확인 | 중단 시 권장 |

## 5. 라운드별 결과 데이터 수집 항목

라운드별 결과 데이터는 각 라운드에서 사용자가 어떤 목표 위치를 기억해야 했고, 성공/실패 여부가 어땠는지를 확인하기 위한 데이터이다.

| 구분 | 수집 항목 | 코드 필드명 | 수집 시점 | 수집 방법/출처 | 수집 목적 | 비고 |
|---|---|---|---|---|---|---|
| 라운드별 결과 | 라운드 목록 | `resultDetail.rounds` | 게임 종료 시 | 게임 내부 누적 | 라운드 단위 결과 저장 | 필수 |
| 라운드별 결과 | 라운드 번호 | `roundNo` | 라운드 시작 시 | 게임 내부 생성 | 몇 번째 라운드인지 식별 | 필수 |
| 라운드별 결과 | 목표 오브젝트 유형 | `targetType` | 라운드 시작 시 | 게임 내부 생성 | 전구로 고정된 목표 대상 확인 | 필수 |
| 라운드별 결과 | 목표 개수 | `targetCount` | 라운드 시작 시 | 난이도 설정 | 기억해야 할 위치 개수 확인 | 필수 |
| 라운드별 결과 | 격자 크기 | `gridSize` | 라운드 시작 시 | 난이도 설정 | 2x2, 3x3, 4x4 난이도 구분 | 필수 |
| 라운드별 결과 | 라운드 성공 여부 | `correct` | 라운드 종료 시 | 게임 내부 계산 | 해당 라운드 성공 여부 확인 | 필수 |
| 라운드별 결과 | 실패 사유 | `failReason` | 라운드 종료 시 | 게임 내부 계산 | 시간 초과, 오답 제한 등 실패 원인 확인 | 실패 시 필수 |
| 라운드별 결과 | 라운드 소요 시간 | `durationMs` | 라운드 종료 시 | 게임 내부 시간 계산 | 라운드별 반응 및 수행 흐름 분석 | 필수 |
| 라운드별 결과 | 정답 클릭 수 | `correctClickCount` | 라운드 진행 중 | 터치 이벤트 | 목표 위치를 맞게 누른 횟수 확인 | 필수 |
| 라운드별 결과 | 오답 클릭 수 | `wrongClickCount` | 라운드 진행 중 | 터치 이벤트 | 잘못 누른 횟수 확인 | 필수 |
| 라운드별 결과 | 힌트 사용 수 | `hintCount` | 힌트 사용 시 | 힌트 버튼 이벤트 | 도움 필요 정도 확인 | 권장 |

## 6. 과정 데이터 수집 항목

과정 데이터는 단순 성공/실패뿐 아니라 사용자가 문제를 해결하는 동안 어떤 흐름으로 상호작용했는지 확인하기 위한 데이터이다.

| 구분 | 수집 항목 | 코드 필드명 | 수집 시점 | 수집 방법/출처 | 수집 목적 | 비고 |
|---|---|---|---|---|---|---|
| 과정 데이터 | 전체 라운드 수 | `metrics.roundTotal` | 게임 종료 시 | 설정값 | 계획된 수행량 확인 | 필수 |
| 과정 데이터 | 진행한 라운드 수 | `metrics.playedRoundCount` | 게임 종료 시 | 게임 내부 누적 | 실제 참여량 확인 | 필수 |
| 과정 데이터 | 성공 라운드 수 | `metrics.correctRoundCount` | 게임 종료 시 | 게임 내부 누적 | 수행 성공 정도 확인 | 필수 |
| 과정 데이터 | 실패 라운드 수 | `metrics.failedRoundCount` | 게임 종료 시 | 게임 내부 누적 | 실패 빈도 확인 | 필수 |
| 과정 데이터 | 시간 초과 라운드 수 | `metrics.timeoutRoundCount` | 게임 종료 시 | 게임 내부 누적 | 시간 제한으로 인한 실패 확인 | 권장 |
| 과정 데이터 | 전체 정답 클릭 수 | `metrics.correctClickCount` | 게임 종료 시 | 터치 이벤트 누적 | 위치 기억 성공 클릭 수 확인 | 필수 |
| 과정 데이터 | 전체 오답 클릭 수 | `metrics.wrongClickCount` | 게임 종료 시 | 터치 이벤트 누적 | 오답 선택 빈도 확인 | 필수 |
| 과정 데이터 | 전체 힌트 사용 수 | `metrics.hintCount` | 게임 종료 시 | 힌트 이벤트 누적 | 도움 필요 정도 분석 | 권장 |
| 과정 데이터 | 전체 시도 수 | `metrics.attemptCount` | 게임 종료 시 | 정답+오답 클릭 합산 | 전체 선택 시도량 확인 | 필수 |
| 과정 데이터 | 전체 상호작용 수 | `metrics.interactionCount` | 게임 종료 시 | 클릭+힌트 합산 | 전반적 상호작용량 확인 | 권장 |
| 과정 데이터 | 클릭 정확도 | `metrics.clickAccuracy` | 게임 종료 시 | 정답 클릭 / 전체 클릭 | 오답 대비 정답 선택 비율 확인 | 권장 |
| 과정 데이터 | 라운드 정확도 | `metrics.roundAccuracy` | 게임 종료 시 | 성공 라운드 / 전체 라운드 | 라운드 단위 성공률 확인 | 권장 |
| 과정 데이터 | 완료율 | `metrics.completionRate` | 게임 종료 시 | 진행 라운드 / 전체 라운드 | 중도 이탈 또는 수행 완료 정도 확인 | 필수 |
| 과정 데이터 | 시작 전 컨디션 | `condition.before` | 게임 시작/종료 시 | 사용자 입력 또는 기본값 | 기분/수면 상태와 수행 결과 참고 | standard 중심 |
| 과정 데이터 | 종료 후 체감 상태 | `condition.after` | 게임 시작 메시지 또는 확장 시 | 사용자 입력 | 체감 난이도, 피로, 도움 필요 여부 참고 | 구현 확장 권장 |

## 7. 오류 데이터 수집 항목

오류 데이터는 게임 실행 중 문제가 발생했을 때 원인 추적과 디버깅을 위해 수집하는 데이터이다.

| 구분 | 수집 항목 | 코드 필드명 | 수집 시점 | 수집 방법/출처 | 수집 목적 | 비고 |
|---|---|---|---|---|---|---|
| 오류 데이터 | 오류 코드 | `errorCode` | 오류 발생 시 | 게임 내부 오류 처리 | 오류 원인 추적 | 오류 없으면 `null` |
| 오류 데이터 | 오류 메시지 | `errorMessage` | 오류 발생 시 | 게임 내부 오류 처리 | 내부 디버깅 | 사용자 노출 문구와 별도 |
| 오류 데이터 | 실행 상태 | `status` | 게임 종료 시 | 게임 내부 계산 | `completed`, `abandoned`, `error` 구분 | 필수 |
| 오류 데이터 | 오류 발생 단계 | `errorPhase` | 오류 발생 시 | 게임 내부 상태값 | 시작, 미리보기, 플레이, 결과 반환 중 어느 단계인지 확인 | 권장 |
| 오류 데이터 | 결과 반환 실패 여부 | `completeSendFailed` | 앱으로 결과 전달 실패 시 | `postMessage` 또는 bridge 처리 | 앱 연동 오류 추적 | 권장 |

## 8. 게임별 상세값 수집 항목

게임별 상세값은 `빛나는 전구를 찾아라` 게임에서만 의미 있는 특수 데이터이다. 공통 결과 필드를 계속 늘리지 않고 `resultDetail` 내부에 저장하는 방식을 우선 고려한다.

| 구분 | 수집 항목 | 코드 필드명 | 수집 시점 | 수집 방법/출처 | 수집 목적 | 비고 |
|---|---|---|---|---|---|---|
| 게임별 상세값 | 적용 테마 | `resultDetail.theme` | 게임 종료 시 | 기본값 | 전구 테마 고정 여부 확인 | `bulb` 고정 |
| 게임별 상세값 | 격자 크기 | `resultDetail.gridSize` | 게임 종료 시 | 난이도 설정 | 기억 위치 수와 화면 복잡도 확인 | EASY 2, NORMAL 3, HARD 4 |
| 게임별 상세값 | 라운드당 목표 개수 | `resultDetail.targetCountPerRound` | 게임 종료 시 | 난이도 설정 | 한 라운드에서 기억해야 한 위치 수 확인 | EASY 2, NORMAL 3, HARD 4 |
| 게임별 상세값 | 라운드 제한 시간 | `resultDetail.timeLimitSec` | 게임 종료 시 | 설정값 | 시간 제한 조건 확인 | 기본 60초 |
| 게임별 상세값 | 라운드당 최대 오답 수 | `resultDetail.maxWrongPerRound` | 게임 종료 시 | 게임 내부 고정값 | 오답 제한 조건 확인 | 현재 3회 |
| 게임별 상세값 | 전구 목표 고정 여부 | `resultDetail.rounds[].targetType` | 게임 종료 시 | 라운드별 결과 로그 | 모든 난이도에서 목표가 전구로만 생성되는지 확인 | 모든 라운드 `yellow` |
| 게임별 상세값 | 라운드 상세 로그 | `resultDetail.rounds` | 게임 종료 시 | 게임 내부 누적 | 라운드별 성공/실패 및 수행 흐름 확인 | 상세 분석용 |

## 10. 수집 제외 항목

아래 항목은 WebView 게임이 직접 생성하거나 수집하는 항목이 아니라, 앱 또는 서버가 보유한 값과 게임 결과를 결합하여 저장하는 항목이다.

| 제외 항목 | 제외 이유 |
|---|---|
| `userId` | 사용자 식별값은 앱/서버가 보유 |
| `seniorId` | 시니어 사용자 식별값은 앱/서버가 보유하고 게임에는 전달값으로만 포함 |
| `guardianId` | 보호자 정보는 앱/서버에서 결합 |
| `assignmentId` | 과제 또는 배정 정보는 앱/서버에서 관리 |
| `alarmId` | 알림 정보는 앱/서버에서 관리 |
| 의료적 진단 결과 | 본 게임 결과는 인지 저하 판정 목적이 아님 |
| 음성 원본 데이터 | 게임은 마이크 권한 요청, 음성 녹음, STT 처리를 직접 수행하지 않음 |
| AI 판단 결과 | 게임 자체는 AI 판단을 수행하지 않고, 앱/AI가 전달한 선택값만 입력으로 처리 |
