# 빛나는 전구를 찾아라 QA 체크리스트

이 문서는 `빛나는 전구를 찾아라` 게임의 현재 구현 기준 QA 체크리스트입니다. 화면 표시명은 `위치 기억활동`이며, 확인 결과는 `통과 / 실패 / 보류` 중 하나로 적고 실패 시 비고란에 재현 조건을 남깁니다.

## 적용 범위

| 구분 | 내용 |
| --- | --- |
| 게임명 | 빛나는 전구를 찾아라 |
| 화면 표시명 | 위치 기억활동 |
| game_key | `banditburi-game` |
| 지원 모드 | `standard`, `reminder`, `care`, `ai_assisted` |
| 주요 활동 | 잠시 보인 불빛 위치를 기억한 뒤 같은 위치를 다시 선택하는 위치 기억 훈련 |
| 주요 테마 | 전구, 새, 휴대폰, 무궁화 방해 요소 |

## QA 참고 메모

- 표준 모드는 사용자가 난이도와 설정을 직접 조절하는 B2C 흐름입니다.
- 알림 모드는 앱/보호자 설정값으로 바로 실행하고, 완료 후 짧은 결과 메시지 뒤 자동 복귀하는 흐름입니다.
- 케어 모드와 AI 연동 모드는 화면 통계를 숨기고, 2x2 중심의 과제 집중형 UI와 부드러운 안내 문구를 사용합니다.
- AI 연동 모드는 웹뷰가 직접 마이크 권한이나 STT 처리를 담당하지 않고, 앱이 전달한 텍스트/명령을 받을 수 있는 구조로 보는 것이 맞습니다.
- 시니어 대상 게임이므로 강한 플래시, 부정적 오답음, 실패감을 주는 문구, 작은 터치 영역은 우선 점검 대상입니다.
