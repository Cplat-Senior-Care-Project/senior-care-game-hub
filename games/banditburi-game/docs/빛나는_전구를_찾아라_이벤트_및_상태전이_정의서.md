# 빛나는 전구를 찾아라 이벤트 및 상태전이 정의서

## 1. 문서 개요

이 문서는 `빛나는 전구를 찾아라` 게임의 모든 상태(State)와 상태 간 전이(Transition)를 정의한다. Cplat 개발팀이 게임 클라이언트 구현 및 앱-게임 연동 시 참조하는 기준 문서다.

참조 문서

- `빛나는_전구를_찾아라_README_실행_가이드.md`
- `빛나는_전구를_찾아라_인터페이스_명세서.md`
- `빛나는_전구를_찾아라_데이터_수집_항목표.md`
- `modes/*/config/game.config.json`

## 2. 상태 목록

게임 내 존재하는 모든 상태를 정의한다. 각 상태는 화면 단위가 아닌 게임 로직 단위로 구분한다.

| 상태 ID | 상태명 | 설명 |
|---|---|---|
| S-01 | LOADING | 게임 에셋, 음성, 이미지, config 로딩 중 |
| S-02 | START | 시작 화면 표시 및 게임 진입 대기 상태 |
| S-03 | TUTORIAL | 게임 방법/튜토리얼 표시 중 |
| S-04 | CONDITION_CHECK | 시작 전 기분/수면 시간 등 컨디션 체크 입력 중 |
| S-05 | DIFFICULTY_SELECT | 난이도 선택 대기 상태 |
| S-06 | COUNTDOWN | 3초 시작 카운트다운 진행 중 |
| S-07 | PREVIEW | 빛나는 전구 위치 노출 중, 기억 단계 |
| S-08 | ANSWER | 전구가 꺼진 뒤 같은 위치 선택 대기 중 |
| S-09 | HINT | 힌트 표시 중, 정답 위치 일부/전체 재노출 |
| S-10 | FEEDBACK | 정답/오답/라운드 종료 피드백 표시 중 |
| S-11 | PAUSED | 일시정지 모달 표시 중 |
| S-12 | FINISH_CHECK | 마무리 컨디션/도움 필요 여부 등 입력 중 |
| S-13 | SCORE | 표준 모드 점수 화면 표시 중 |
| S-14 | RESULT | 최종 결과 화면 표시 중 |
| S-15 | ERROR | 오류 화면 또는 복구 불가 오류 상태 |

## 4. 이벤트 명세

게임-앱 간 `postMessage` 이벤트 목록이다. 이벤트명과 payload 상세는 공통 연동 규칙 문서에서 확정하되, 현재 구현 기준 주요 이벤트는 아래와 같다.

### 4-1. 게임 -> 앱

| 이벤트명 | 발생 시점 |
|---|---|
| GAME_READY | 에셋/config 로딩 완료 후 게임 초기화 완료 시 |
| GAME_STARTED | 시작 카운트다운 진입 또는 실제 플레이 세션 시작 시 |
| GAME_COMPLETED | 모든 문항 정상 완료 후 결과 확정 시 |
| GAME_ABANDONED | 시작 전/진행 중 사용자 이탈, WebView 종료, 중도 종료 시 |
| GAME_RETURN_REQUESTED | 결과 화면 자동 복귀 또는 돌아가기 버튼 클릭 시 |
| EXTERNAL_ANSWER_APPLIED | AI/앱에서 전달한 외부 선택값을 게임에 반영한 시점 |

### 4-2. 앱 -> 게임

| 이벤트명 | 발생 시점 |
|---|---|
| APP_INIT | WebView 로드 전후 config 및 세션 초기값 전달 |
| APP_PAUSE | 앱 백그라운드 전환 또는 보호자/시스템 일시정지 요청 시 |
| APP_RESUME | 앱 복귀 시 |
| APP_MUTE | 음소거 설정 변경 시 |
| APP_EXIT_REQUEST | 앱에서 강제 종료 요청 시 |
| EXTERNAL_ANSWER | AI연동 모드 전용. 앱/AI가 선택 위치 또는 선택값을 게임에 전달 |

`EXTERNAL_ANSWER` 예시:

```js
window.postMessage({
  type: "EXTERNAL_ANSWER",
  payload: {
    selected_index: 2,
    selected_position_index: 2,
    selected_answer: "2",
    input_type: "voice",
    raw_transcript: "두 번째",
    confidence: 0.86
  }
}, "*");
```

선택값은 `selected_index`, `selected_position_index`, `selected_answer` 순으로 숫자 변환 가능한 값을 사용한다. 인덱스는 앱/AI 연동 기준 1부터 시작하는 값을 권장한다.

## 6. 구현 참고

- 내부 로직의 핵심 phase는 `home`, `countdown`, `preview`, `playing`, `hint`, `between`, `paused`, `finish`, `score`, `postgame`, `result`로 운용된다.
- 본 문서의 S-08 `ANSWER`는 구현상 `playing` phase에 해당한다.
- 본 문서의 S-10 `FEEDBACK`은 구현상 `between` phase에 해당한다.
- 표준 모드는 `finish`, `score`를 사용할 수 있고, 알림/케어/AI연동 모드는 대부분 `result`로 바로 이동한다.
- 앱 브리지 우선순위는 `window.ReactNativeWebView.postMessage`, `window.webkit.messageHandlers.gameBridge.postMessage`, 로컬 콘솔 mock 순이다.
